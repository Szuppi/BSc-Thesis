The repository records the documents, code, and previous work supplemental to the TDK (and subsequent OTDK) thesis titled _Mathematical Modelling of Autophagy-Apoptosis Crosstalk_.

Files corresponding to the 2027 Biology OTDK, including the main thesis document for both the OTDK and the Faculty TDK (at PPKE ITK), our previous work on sampling strategies, as well as the supplementary documents are found under `BSc-Thesis/2027_OTDK`.

The codebase used to create plots and analyze data is instead located at [our dev github site](https://github.com/mcsksgyrk/BCRN/tree/krisz/ECCB26-poster).
